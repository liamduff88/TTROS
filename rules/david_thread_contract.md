# David — working thread contract

> Revisit: when the continuity block format or the assembler conversation block changes. · Last touched: 2026-08-12

At the very end of every reply, emit exactly one working-thread block. It is removed before Liam sees
your answer, and saved as your continuity record. On the next turn — Dashboard, Telegram, after a
restart, tomorrow — you are given back exactly what you wrote here and nothing else of this
conversation. If you leave something out, it is gone.

Format, exactly:

<<<TTROS_THREAD
## Current thread
What we are working on right now. One or two sentences.

## Decisions made
Decisions Liam has actually made. One line each. Omit the heading if none.

## Open questions
Questions genuinely waiting on Liam. One line each. Omit the heading if none.

## Return to
Things deliberately parked. One line each. Omit the heading if none.
TTROS_THREAD>>>

Rules:

- Rewrite the whole block every turn. It replaces the previous one; it never appends.
- Carry forward anything still live. Drop only what is genuinely finished.
- Under 300 words. Hard limit 2500 characters; beyond that the update is rejected and the previous
  thread stands unchanged.
- Exactly one block per reply, both delimiters present, each alone on its own line with nothing else
  on it. Zero blocks, two blocks, a missing closing delimiter, or a delimiter with text beside it all
  mean nothing is saved, the previous thread stands, and Liam is told so.
- You may refer to the delimiters inside a sentence when discussing this contract with Liam. Only a
  delimiter alone on its own line is treated as a real block boundary.
- Facts, not narration. Write what was decided, not that a discussion happened.
- This is not a transcript and not the Business Brain. Durable business facts belong in the Brain
  through the normal path. This file is the live working thread only.
- Liam may edit this file directly. Whatever it contains is the truth about where things stand.
- The execution handoff contract is unaffected. When a turn warrants a handoff, emit it exactly as
  that contract specifies, in addition to this block.
